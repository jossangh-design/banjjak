반짝 개인정보 처리방침

시행일: 2026년 11월 17일

1. 반짝이 다루는 정보

반짝은 선생님 컴퓨터에서 돌아가는 프로그램이에요. 일정·학생 기록 등 반짝에 넣은 자료는 선생님 컴퓨터에만 저장되고, 반짝 개발자나 다른 곳으로 보내지 않아요.

2. 구글 캘린더 연결(선택)

선생님이 설정에서 ‘구글로 로그인’을 누른 경우에만 아래 정보를 구글에서 받아요.

  • 구글 계정 이메일 주소: 어느 계정으로 연결했는지 화면에 보여 주는 데만 써요.
  • 반짝이 만든 캘린더(‘반짝 업무’, ‘반짝 학교 일정’)와 그 안의 일정: 반짝 달력과 구글 캘린더의 일정을 서로 맞추는 데만 써요.

반짝은 선생님의 다른 캘린더(개인 일정 등), 메일, 연락처, 드라이브 파일은 볼 수 없어요. 그런 권한을 요청하지 않아요.

3. 저장과 보호

  • 구글 로그인 정보(토큰)는 선생님 컴퓨터에 윈도우 계정 암호화로 저장돼요. 구글 비밀번호는 반짝이 보거나 저장하지 않아요.
  • 일정은 선생님 컴퓨터와 선생님 구글 계정 사이에서만 오가요. 반짝 개발자의 서버는 없어요.

4. 다른 곳에 주지 않아요

구글에서 받은 정보를 다른 사람이나 회사에 팔거나 넘기지 않고, 광고에 쓰지 않아요. 반짝이 구글 API에서 받은 정보를 쓰고 옮기는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따라요.

5. 연결 끊기와 지우기

  • 반짝 설정 → 달력 동기화 설정 → 연결 끊기를 누르면 컴퓨터에 저장된 구글 로그인 정보가 지워지고 구글 쪽 허용도 거둬요.
  • 구글 계정의 연결된 앱에서도 언제든 반짝의 허용을 거둘 수 있어요.
  • ‘반짝 업무’, ‘반짝 학교 일정’ 캘린더는 구글 캘린더에서 직접 지울 수 있어요.

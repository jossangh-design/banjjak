# 반짝

선생님을 위한 윈도우 바탕화면 위젯 — 달력 · 일정 · 할 일 · 학사일정 · 평가 · 우리 반 관리

## 설치
1. 오른쪽 **Releases**에서 최신 버전의 `Banjjak-v○○.zip`을 받습니다.
2. 원하는 곳에 압축을 풀고 `Banjjak` 폴더의 `Banjjak.exe`를 실행합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
   - 업무 PC에 설치하기 전에 학교 정보 담당자에게 확인해 주세요.

## 업데이트
켤 때 하루 한 번 새 버전을 확인해 자동으로 바뀝니다.

## 내 자료
모든 기록은 내 PC에만 암호화되어 저장되며 어디에도 올라가지 않습니다.
PC를 바꿀 때는 ☰ 메뉴 → 내보내기, 새 PC에서 ☰ 메뉴 → 가져오기를 쓰세요.
